# Бот Polytech Plan

Бот получает расписание и дедлайны через Polytech Plan API. Команда
`/deadline` отправляет текст в `POST /api/deadline/parse/` и показывает
предварительный результат. После подтверждения бот отправляет его в
`POST /api/deadline/confirm/`. API сохраняет и объединяет дедлайны.

## Запуск

Запустите [Polytech Plan API](../polytech_plan/polytech_plan_api/README.md).
Скопируйте `src/settings/template.env` в `src/settings/.env` и укажите
`TOKEN`, `API_PATH` и настройки `POSTGRES_*`. При обновлении сохраните прежние
параметры PostgreSQL и том `teha_bot`, чтобы бот использовал существующие
профили. При первом запуске бот создаёт таблицы настроек автоматически.
При запуске на одной машине бот обращается к API по адресу
`http://api:8000` через сеть `poly-shared`. Создайте её один раз перед
запуском API и бота. В существующем `.env` API добавьте `api` в список
`DJANGO_ALLOWED_HOSTS`.
Если API находится на другом сервере, укажите его базовый URL в `API_PATH`.

```bash
docker compose up -d --build
```

Для локального запуска с опубликованным портом API используйте
`API_PATH=http://localhost:8000`. PostgreSQL можно запустить отдельно
командой `docker compose -f compose.dev.yaml up -d`. Для другого адреса
PostgreSQL укажите `POSTGRES_HOST`.

```bash
uv run --locked src/main.py
```

## Команды

- `/start` и `/profile` помогают указать группу и настроить напоминания.
- `/day`, `/nextday`, `/week` и `/semester` показывают расписание.
- `/reminder` показывает расписание на сегодня с кнопкой дедлайнов на сегодня и завтра.
- `/deadlines` показывает дедлайны с понедельника по воскресенье текущей недели.
- `/all_deadlines` показывает все дедлайны начиная с сегодняшнего дня.
- `/deadline` принимает текст задания, фото и документы. `/cancel` отменяет ввод.
- `/delete_deadline` удаляет дедлайн группы после подтверждения.
- `/sessia` (или `/session`) показывает задания группы к сессии. Можно указать семестр, например `/sessia 2026-2`.
- `/session_add` отправляет свободный текст после подтверждения. API определяет предмет, разбивает текст на задания и извлекает сроки. Бот показывает обновлённый список по предмету.
- `/session_add manual` добавляет одно задание вручную. На первой строке укажи предмет и при необходимости срок через `|`, на следующих строках напиши задание.

В личке профиль привязан к пользователю, а в группе Telegram им пользуются
все участники чата. Для работы в группе включите темы и дайте боту право
«Управление темами». Администратор может запустить `/setup` внутри
существующей темы «Дедлайны», чтобы привязать её, или в общем чате, чтобы
создать тему. Напоминания по умолчанию отправляются в 08:00 по Москве с
понедельника по субботу.

Настройки профиля и уведомлений, дата последней отправки и привязка темы
хранятся в PostgreSQL бота. Дедлайны и их файлы хранятся в Polytech Plan API.

После `/deadline` можно отправить до пяти фото или документов по 20 МиБ,
в том числе альбомом. Напишите текст задания в подписи или отдельным
сообщением после файлов. После подтверждения бот загрузит файлы в API.
API принимает вложения при создании нового дедлайна. Если совпадение уже
есть, бот предложит подтвердить только текст.

Бот показывает ссылки на файлы в списках дедлайнов и под кнопкой
«Показать дедлайны». Укажите доступный пользователям адрес
`PUBLIC_API_URL` в окружении API. Ссылки открываются без авторизации.

```bash
PYTHONPATH=src uv run --locked python -m unittest discover -s tests -v
```
